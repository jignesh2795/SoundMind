# M1.1 — TasteProfile and Listening History

M1.1 adds persistent listening events and a transparent TasteProfile.

Events: play, complete, skip, like, dislike, replay. Events may carry timestamp, context, and seconds played.

Initial evidence weights: play +0.15, complete +0.35, like +1.00, replay +1.25, skip -0.75, dislike -1.00.

Evidence uses a configurable 30-day exponential half-life by default.

Music DNA describes the track; TasteProfile describes observed listener behavior. The retrieval fusion layer now has an explicit preference_score channel.
